How to install

New Outlook / Outlook on the web

  1. Click Copy for Outlook.
  2. Settings → Accounts → Signatures → New signature.
  3. Paste (Ctrl+V), name it, save and set as default.

Classic Outlook (Windows)

  1. Click Download .htm.
  2. Press Win+R, open %APPDATA%\Microsoft\Signatures.
  3. Move the file there, then File → Options → Mail → Signatures and select it.

Gmail

  1. Click Copy for Gmail.
  2. Gmail → Settings (gear) → See all settings → General → Signature → Create new.
  3. Paste, then Save Changes at the bottom. Don't resize the images.

Outlook for Mac

  1. Click Copy for Outlook.
  2. Outlook → Settings → Signatures → +.
  3. Paste, name it and save.
